# EventCast.pro Admin Baseline - Version 1 to Version 2.1 Change Register

**Prepared:** 8 August 2026

## 1. Retained without material change

The livestream-first provider product, primary customer order, English-first launch, no recurring-events requirement, separate provider and platform surfaces, SRS plus Media Agent target, optional YouTube, optional page modules, Guest Memories terminology and auto-approval default, trustworthy analytics rule, Partners and Event Credits, Support direction, Super Admin principles, R2 live role, B2 authoritative recording role, 90-day replay, 12-month event page, and one-bounded-slice workflow remain accepted.

## 2. Refined decisions

The admin framework is now explicitly the existing Next.js App Router and TypeScript application structured as a route-based modular monolith. The public Worker remains separate.

The URL model now explicitly supports business subdomains, neutral EventCast links, primary canonical URL, aliases, and future customer domains. Tenant-scoped slug uniqueness is verified by the live database.

The template strategy now includes a canonical package, exact template version, TLF-001 legacy adapter, immutable release assets, GrapesJS retirement, and Layer Studio preservation.

The event contract now explicitly separates Draft Input, Canonical Record, and Public Config and uses one authoritative scheduled timestamp.

The billing position is refined: exact commercial plans and eight-hour package values are deferred, the disabled wallet remains closed, and the legacy ₹499 Create Event debit is retired from the new flow. Beta Entitlement is a temporary closed-beta access mechanism, not a price plan.

## 3. Superseded decisions

The separate React Router Framework Mode Admin V2 target is superseded by the existing Next.js application decision.

The idea that custom domains are wholly future is refined. Business subdomain and neutral-link foundations are core architecture; customer-owned domains and domain resale remain future.

The idea of retaining GrapesJS for later is superseded. GrapesJS is removed; EventCast Layer Studio is the preserved future editor.

The earlier initial pricing examples are no longer final product authority.

## 4. New accepted decisions

New accepted decisions cover the business-subdomain URL, business-root landing page, neutral link, primary URL aliases, EventCast Direct tenant, private EventCast Direct operations data, wildcard routing exclusions, immutable event identity, three-layer event contract, canonical scheduled timestamp, template-version pinning, public legacy portal retirement, controlled legacy cleanup, ₹499 debit retirement, Beta Entitlement, live schema findings, and the Route-Based Draft Event Foundation first slice.

## 5. New verified evidence

Claude Opus revalidated the repository at HEAD `8e7537e`, confirmed the split between SRS public delivery and Restreamer provider UI, confirmed the monolithic provider page, confirmed the unwired event contract, and mapped every Version 1 decision.

The live Supabase preflight verified 53 event columns, required legacy fields, public default visibility, visibility and deployment checks, tenant-scoped slug uniqueness, RLS enabled, five policies, three indexes, and no non-system triggers.

## 6. Decisions deliberately left open

Exact migration SQL, exact shared-package folder paths, exact OTP and SMS providers, exact commercial plans and prices, exact custom-domain commercial offering, exact Layer Studio integration, and final archive or deletion policy for historical customer directories and scratch scripts remain task-level or future decisions.

These open details do not block the first Draft Event slice.


## 7. Version 2.1 correction pass

Version 2.1 adds a deterministic visible Table of Contents, makes the business-subdomain root behaviour explicit, records EventCast Direct internal operations data as a private product decision, corrects the livestream and VOD architecture diagrams, fixes wording and YouTube decision ordering, updates file names and checksums, and leaves the approved first implementation slice unchanged.
