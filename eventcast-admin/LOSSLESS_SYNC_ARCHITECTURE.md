# Lossless Roundtrip Sync - 4-File Architecture

## Overview

The GrapesJS template editor now uses a **lossless 4-file architecture** that preserves 100% of the editor state during save/load cycles. This eliminates template corruption and ensures drag-and-drop layers, absolute positioning, and all visual styles are perfectly preserved.

## The 4-File Structure

Each template now consists of:

1. **`index.html`** - HTML structure with dynamic placeholders and metadata
2. **`style.css`** - Visual styles edited by GrapesJS
3. **`script.js`** - Client-side logic (Supabase, streaming, etc.) — **NEVER touched by GrapesJS**
4. **`gjs-project.json`** - GrapesJS internal editor state (NEW)

## How It Works

### Loading (GET /api/local-sync)

**Lossless Mode** (if `gjs-project.json` exists):
- Reads `gjs-project.json` and returns it as `projectData`
- Also returns `style.css` content
- Frontend calls `editor.loadProjectData(projectData)` for 100% state restoration

**Legacy Mode** (backward compatibility):
- Parses `index.html` and extracts body content
- Returns `html` and `css` separately
- Frontend calls `editor.setComponents(html)` and `editor.setStyle(css)`

### Saving (POST /api/local-sync)

The editor sends:
```json
{
  "slug": "template-name",
  "html": "<div>...</div>",
  "css": "body { ... }",
  "projectData": { "pages": [...], "styles": [...], ... }
}
```

The backend:

1. **Saves `gjs-project.json`** - Complete GrapesJS state (lossless)
2. **Saves `style.css`** - Full CSS stylesheet
3. **Reconstructs `index.html`**:
   - Preserves original `<head>` (meta tags, fonts, etc.)
   - Preserves custom `<div id="loader">...</div>` block
   - Injects new GrapesJS HTML body content
   - Preserves all original `<script src="...">` tags
   - Converts px positions to % for mobile responsiveness
4. **Ignores `script.js`** - Protected client-side logic

## Key Benefits

✅ **100% Lossless** - All editor state preserved (layers, components, styles, etc.)  
✅ **CSS Sync** - Style changes are now saved back to `style.css`  
✅ **No More Corruption** - Drag-and-drop positioning works perfectly across sessions  
✅ **Backward Compatible** - Legacy templates without `gjs-project.json` still work  
✅ **Separation of Concerns** - Dynamic scripts are completely protected  
✅ **Mobile Responsive** - Automatic px→% conversion maintains responsiveness

## Migration Path

### For Existing Templates

When you first open an existing template (without `gjs-project.json`):
- ⚠️  It loads in **LEGACY MODE** (parsing HTML/CSS)
- Make any edit and click **Save**
- ✅ Now it saves `gjs-project.json` and switches to **LOSSLESS MODE**
- All future edits will be 100% lossless

### For New Templates

- Create template files: `index.html`, `style.css`, `script.js`
- Open in GrapesJS editor
- First save automatically creates `gjs-project.json`
- ✅ Template is now in lossless mode

## Technical Details

### Backend Changes (`route.ts`)

- **GET Handler**: 
  - Checks for `gjs-project.json` existence
  - Returns `projectData` if found, otherwise falls back to HTML/CSS parsing
  
- **POST Handler**:
  - Accepts `html`, `css`, and `projectData`
  - Saves all three to their respective files
  - Reconstructs `index.html` preserving structural elements

### Frontend Changes (`GrapesEditor.tsx`)

- **Load Handler**:
  - Checks if `projectData` exists in API response
  - Calls `editor.loadProjectData()` for lossless mode
  - Falls back to `editor.setComponents()` + `editor.setStyle()` for legacy mode
  
- **Save Handler**:
  - Extracts `projectData` using `editor.getProjectData()`
  - Extracts `css` using `editor.getCss()`
  - Sends all three to backend API

## Console Logging

Both frontend and backend now log the sync mode:

```
✅ Loaded template "my-event" in LOSSLESS mode (gjs-project.json found)
✅ Saved: index.html, style.css, gjs-project.json
```

or

```
⚠️  Loaded template "legacy-event" in LEGACY mode (gjs-project.json not found)
```

## File Sizes

Typical `gjs-project.json` file size: **10-50 KB** (compressed JSON)  
This is negligible compared to the benefits of lossless editing.

## Important Notes

- **Never manually edit `gjs-project.json`** - It's auto-generated by GrapesJS
- **`script.js` is sacred** - The API will never touch this file
- **Backups are automatic** - `index.html.bak` is created on every save
- **Production safety** - Local sync is disabled in production builds
